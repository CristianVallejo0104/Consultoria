**Algoritmo Paso a Paso de la Búsqueda Binaria:**

1. **Iniciar**:
   - Establece dos índices, `left` = 0 y `right` = n-1 (donde n es el tamaño del array).

2. **Repetir until left >= right**:
   - Calcula el índice medio `(mid)`: `mid = left + (right - left) // 2`.

3. **Verificar**:
   - Si `array[mid]` == elemento busqué, está encontrado.
   - Si `array[mid] < elemento buscado`, actualiza `left` a `mid + 1`.
   - De lo contrario, si `array[mid] > elemento buscado`, actualiza `right` a `mid - 1`.

4. **Fin**:
   - El proceso se repite hasta que el valor sea encontrado o `left >= right`, indicando que el elemento no está presente en la lista.

Aquí tienes un ejemplo práctico usando Python:

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        
        if arr[mid] == target:
            return mid  # Elemento encontrado
